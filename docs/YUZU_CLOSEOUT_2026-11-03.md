# Yuzu 整合收尾

用户最新裁定：“新面板和减延迟都实机验收通过，现在做收尾。”据此关闭面板与自有减延迟的用户验收待办。本记录整理本轮已批准实现，不扩大到尚未批准的重构或插件适配。

## 已验收的交付范围

| 项目 | 最终状态 |
|---|---|
| Yuzu 联机 | 作为上游连接方式选项接入，真实对端联机已通过用户验收；Yuzu 模式暂不适配回滚 |
| 自有减延迟 | 保留自动 / 0～25 帧设置和真实 LDN 对端门槛；用户明确实机验收通过 |

| 后台运行 | 影片与房间等待的失焦暂停问题已修复，之前的用户验收保持通过 |

“减延迟实机通过”记录用户的功能与使用验收，不换算成未测得的毫秒数。任意新增 NRO 仍需配套 PC 编译产物，未增加通用 NRO 直接运行功能。

## 验证依据

本轮没有改动运行时代码或已验收的二进制，沿用并核对实际完整包证据：更新器 40 项、Console 29 项常规检查、另外启用的真实完整包启动检查 1 项、打包 / 功能检查 10 项通过。默认跳过项及环境边界见[完整包验证](YUZU_FULL_PACKAGE_VALIDATION_2026-11-02.md)。

实物验证覆盖空存档 / 空缓存启动到标题、原样 Fox 资源 mod、三组各满 120 战斗帧并正常退出，以及 0.2.0 实际副本的完整更新、修复、清理后精确回滚。正式 Console 启动和其真实游戏启动链通过；没有用进程存活替代对战验收。

收尾补充核对：当前宿主与暂存的 runtime / SDK 源码一致；延迟扩展和宿主记录匹配；主图形文件与 main 一致；正式 trust.json 与稳定 yuzu 一致；包内二进制、ZIP 与已验证哈希一致；Console 内嵌的 helper 与包内独立 helper 一致；原试用宿主与原工作目录状态保持不变。另检查 README 无冲突标记、Git 无未解决文件、暂存区无游戏数据 / 密钥 / 构建产物以及文本差异格式。

当前宿主从干净 staging 构建，复用了指纹匹配的游戏 / 脚本 DLL，不声称从游戏 dump 全量重编。未具备环境的平台、尚未发布的线上更新通道、端到端延迟量化不冒记通过。很长的绝对 shader 缓存路径仍有已记录的上游限制；正式 Console 默认相对缓存路径已通过实际检查。

## 待用户裁定的稳定合入

当前稳定 yuzu 对应 0.2.0。本轮包含上游基线整合、联机 / mod 加载策略和完整更新机制调整，建议下一稳定版使用 **0.3.0**，尚未采用该版本号。

用户确认版本号方案后，才将其用于正式发行元数据并合入稳定 yuzu。合入时保留原目录本地修改；推送、标签和发布按相应授权处理。验证用 `validation.20261102` 和诊断签名不用于正式发行，也不把测试包序号用作正式通道序号。

更深层的虚拟套接字内部重构、通用 NRO 转换和 Yuzu 回滚继续留在本轮之外。本地完整包验证与用户验收已完成，不将这些新增目标当作本次收尾的阻碍。

本地证据：`build/closeout-20261103`（收尾快照与 validation.json），`build/full-package-validation-20261102`（完整包、运行、更新及截图）。
