# 0.3.0 稳定整合版本（2026-11-03）

用户已批准使用 **0.3.0**。本轮将已验收的 yuzu-dev 整合结果合入本地稳定 yuzu，不执行远程推送、标签或线上发布。

## 版本方案

| 字段 | 值 |
|---|---|
| 显示版本 version | 0.3.0 |
| 更新序号 sequence | 5（承接本地 0.2.0 的序号 4） |
| 通道 channel | yuzu-test |
| 平台 platform | win-x64 |
| 个人扩展已验证游戏版本 game_version | 13.0.4 |
| 最低更新助手 minimum_updater | 2 |
| 更新类型 kind | full |

公开版本号来自发行包生成器写入的 version.json 和签名更新计划。Console / updater Cargo 包自身的 0.1.0 是组件版本，不作为本便携版的对外版本号。发行包和签名清单须由正式构建按本方案生成；既有 validation.20261102 诊断包、诊断签名与测试高序号不改名冒充正式 0.3.0。

## 更新内容

- 基于本轮 main 基线整合个人功能，main 本身保持上游原样。
- Yuzu 联机作为上游连接方式选项接入；共用设置与接口，保留原协议传输，真实对端联机验收通过。Yuzu 模式暂不适配回滚。
- 保留自有减延迟和 F8 新面板，全屏 / 无边框临时置顶以及 F11 切换均由用户实机验收通过。
- 修复影片及本地无线房间等待中的失焦暂停问题，保留上游焦点控制和正常退出。
- 资源 mod 使用上游 Skyline / 原样 ARCropolis 加载，Console 保留导入、启停与管理。包内配套原插件和 PC 编译文件，任意新增 NRO 不属于直接运行能力。
- 图形采用本轮 main 的实现，撤出个人着色器回收和预算优化。
- 更新采用签名完整目标覆盖，允许本地旧程序改变或缺失，支持同版本修复；保留存档、设置与 mod。
- 成功后清理下载 / 暂存 / 过期备份，只留最近一次实际状态备份。已知退役的旧游戏 DLL 与资源后端程序通过签名删除清单移除，并已验证可回滚。

## 验收与构建边界

新面板和减延迟、后台运行、资源 mod、真实对端联机已有用户确认。实际完整包完成空缓存启动和三组各 120 战斗帧的正常退出；旧 0.2.0 副本的完整更新、同版本修复、回滚、玩家资料保留和自动清理均通过。

自动检查包括更新器 40 项、Console 29 项及另外启用的完整包启动 1 项、打包 / 功能 10 项；跳过项、截图、原样 mod 指纹以及失败探测的修正记录见 [完整包验证](YUZU_FULL_PACKAGE_VALIDATION_2026-11-02.md)。本次版本记录与本地合入只改变文档，没有改动用户已验收的运行时代码或二进制。

尚未发布线上 0.3.0 通道，未量化端到端毫秒延迟，未对所有平台或任意第三方 NRO 作兼容承诺。正式打包、源码 / 许可证整备、签名、远端上传及线上下载验证按后续发布授权执行。

## 本地稳定合入

版本说明先在 yuzu-dev 提交，再在已有 yuzu 工作目录执行 `git merge --ff-only yuzu-dev`，保留完整开发与原 yuzu 历史。原目录的 AGENTS.md 未提交字节及 28 份未跟踪资料保存并原样恢复 / 复核；main 和其他工作树不改动。具体提交号与保护检查记录在本机忽略目录 `build/stable-0.3.0-20261103/`。

后续调用完整发行生成器时使用 `--version 0.3.0 --sequence 5 --kind full`，并以最终源码 / 构建生成新的 build_id 和正式签名清单。不复用诊断签名，不将版本确认视为远程发布授权。
